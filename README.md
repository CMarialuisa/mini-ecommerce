# Mini E-Commerce - Console App & xUnit

[![.NET 10.0](https://img.shields.io/badge/.NET-10.0-512BD4?logo=dotnet)](https://dotnet.microsoft.com/)
[![xUnit](https://img.shields.io/badge/Testing-xUnit-blue)](https://xunit.net/)

## Sobre o Projeto
Aplicação de consola desenvolvida em C# (.NET 10) simulando um E-commerce básico. Implementa gestão de catálogo, carrinho de compras com validação de stock e fluxo de checkout, validado através de TDD com **xUnit**. O versionamento segue o padrão **Conventional Commits**.

## Como Executar

**Compilar a Solução:**
```bash
    dotnet build
```

**Executar a Aplicação:**

    dotnet run --project MiniEcommerce.Console/MiniEcommerce.Console.csproj

**Executar os Testes Unitários:**

    dotnet test
